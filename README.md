# LLM by norin - Multimodal Vision LLM & Image Studio

搭載されている **NVIDIA GeForce RTX 4070 Ti (12GB VRAM)** をフル活用した、高速・完全ローカル動作の**マルチモーダルAIチャット＆画像生成スタジオ**です。

外部API（クラウド）へのデータ送信を行わず、すべてローカルマシンのGPU上で推論・画像認識・画像生成を実行します。

---

## 🌟 主な特徴

- 👁️ **マルチモーダル画像認識 (Vision LLM)**:
  - 最先端のVision-Languageモデル **`Qwen/Qwen2-VL-2B-Instruct`** を採用。
  - テキストでの対話はもちろん、**スクリーンショットや写真、図表、コード画像を貼り付けると、AIが画像内容を直接読み取って正確に解説・分析・回答**します。
  - **クリップボード貼り付け (Ctrl+V)** やドラッグ＆ドロップ、画像ファイル選択に対応。
- 🗂️ **会話のタブ形式管理 (マルチセッション)**:
  - ブラウザタブのように、**上部タブバーから「＋」ボタンで新しい会話をいくらでも追加**できます。
  - 各タブの名前（タイトル）は最初の質問内容に応じて自動設定され、ダブルクリックで自由にリネーム可能。
  - 会話履歴はすべてブラウザのローカルストレージに自動保存されるため、**ページを再読み込み（リロード）してもすべてのタブと会話が復元**されます。
  - 不要になった会話はタブの「×」ボタンで個別に削除できます。
- 🎓 **フォルダまるごと画風追加学習スタジオ (LoRA Training - 個人利用専用)**:
  - 好きなイラスト画像群（5〜15枚推奨）をフォルダに入れるか、UI画面からドラッグ＆ドロップするだけで、**RTX 4070 Ti (12GB) のGPU上であなただけの画風LoRAモデルを追加学習**できます。
  - **🤖 Vision AI による自動構図キャプション付与**:
    - 画像だけを配置すれば、常駐しているVision LLM (`Qwen2-VL`) が各画像の被写体を自動言語化。「被写体」と「画風」を綺麗に分離して高精度に学習します。
  - **⚡ 高速学習**:
    - 潜在空間（Latents）とプロンプト埋め込みの事前キャッシュ＆FP16混合精度により、**約2〜3分で学習が完了**。
  - **🎨 学習完了後はワンクリックで即座に出力**:
    - 学習が終わると `backend/loras/<画風名>.safetensors` に自動保存され、画像生成画面の「LoRAモデル選択」に即座に反映。その画風に似た新しいイラストを自由なプロンプトで生成できます。
- 🎨 **1秒未満の爆速ローカル画像生成 (SD-Turbo) & 画風カスタマイズ**:
  - Hugging Face `diffusers` と `stabilityai/sd-turbo` による最新の拡散蒸留（ADD）モデルを搭載。
  - わずか **1ステップ（約 0.5〜1.0 秒）** で高精細な画像を即座に生成。
  - **🖌️ 画風スタイル・プリセット機能**:
    - **アニメ・マンガ調** (Anime / Manga - 新海誠・ジブリ風の鮮やかな色彩と線画)
    - **写真・実写調** (Photorealistic - 超高解像度・被写界深度のあるリアル写真)
    - **水彩画** (Watercolor - 繊細な滲みと透明水彩テクスチャ)
    - **油絵** (Oil Painting - 重厚な筆跡とキャンバス質感)
    - **サイバーパンク** (Cyberpunk - ネオンとダークフューチャーSF)
    - **ピクセルアート** (Pixel Art - レトロな16-bitドット絵)
    - **3Dレンダー** (3D Render - Unreal Engine 5 / Octaneクオリティの立体CG)
  - **🧠 画風追加学習 (LoRA) に対応**:
    - `backend/loras/` フォルダにお手持ちの `.safetensors` LoRAファイルを配置するだけで、UIから自動認識され、ワンクリックで画風や特定キャラクターの適用が可能。
  - **📐 縦横比（アスペクト比）の自由な切り替えに対応**:
    - `1:1` 正方形 (512×512) - アイコン、イラスト
    - `16:9` ワイド横長 (640×360) - PC壁紙、風景画、シネマティック
    - `9:16` スマホ縦長 (360×640) - スマホ壁紙、立ち絵、ポートレート
    - `4:3` 写真横長 (576×432) - 写真構図
    - `3:4` ポスター縦長 (432×576) - ポスター、人物画
  - テキストチャット中に「`/image <プロンプト>`」と入力するだけでも直接画像を生成可能。
- ⚡ **RTX 4070 Ti の VRAM 内で両モデルが完全共存**:
  - Vision LLM (約 4.5GB) + SD-Turbo (約 2.8GB) = **合計約 7.3GB / 12.0GB**。
  - モデルの入れ替えやリロード待ちなしで、**画像認識対話と画像生成の両方を同時に即座に実行**できます。
- 🎛️ **充実した回答アクションツールバー**:
  - ChatGPTやClaudeと同様に、AIの各回答の下に **「👍 良い回答」「👎 不適切」「🔄 再生成」「📋 コピー」** のボタンを設置。
- 💾 **ワンクリック Git 同期 (プッシュ)**:
  - サイドバーの「生成画像をGitへプッシュ」ボタンを押すだけで、生成された画像がローカルの `outputs/` に保存され、自動で GitHub リポジトリ（`main` ブランチ）へコミット＆プッシュされます。
- 📊 **リアルタイム GPU & VRAM モニタリング**:
  - VRAM使用量/総容量（例: `7.3 GB / 12.0 GB`）、GPUステータス、モデル稼働状態を画面上にリアルタイム表示。

## 🚀 クイックスタート

### 1. 必要要件
- OS: Windows 10 / 11 (64-bit)
- GPU: NVIDIA GPU (RTX 4070 Ti 推奨, VRAM 8GB以上)
- Python: 3.10 以上 (3.13対応確認済み)
- Node.js: 18.0 以上

### 2. ワンクリック起動
リポジトリ直下の `start.bat` をダブルクリックするだけで、バックエンドとフロントエンドが同時に起動し、ブラウザでUIが開きます。

```cmd
start.bat
```

ブラウザで `http://localhost:5173` にアクセスしてください。

## 💡 使い方

### 1. 画像を見せて質問する (Vision機能)
1. 入力欄で **Ctrl+V** を押してスクリーンショットを貼り付けるか、📎 ボタンから画像を選択します。
2. 「この画像の内容を解説してください」「このエラーの原因は？」などの質問を入力して送信します。
3. AIが画像の内容を視覚的に読み取り、詳しく回答します。

### 2. 画像を生成する (Image Generation)
1. 上部のタブで **「🎨 画像生成」** を選択（またはチャットで `/image <プロンプト>` と入力）。
2. プロンプトを入力して送信します（例: `A futuristic cyberpunk city with glowing neon lights, 8k resolution`）。
3. 約1秒で高精細な画像が表示され、クリックで拡大プレビューやダウンロードが可能です。

### 3. 生成画像をGitへ保存する
- サイドバーの **「生成画像をGitへプッシュ」** ボタンを押すと、チャット中に生成された画像がローカルの `outputs/` に保存され、自動でGitHubリポジトリにプッシュされます。

### 4. フォルダのイラストから独自の画風を学習する (LoRA画風学習)
1. 画面下のモード切替タブから **「🎓 画風学習 (LoRA)」** を選択します。
2. 画風の名前（例: `my_anime_style`）を入力します。
3. 似せたいイラスト画像（5〜15枚推奨）をドラッグ＆ドロップして「フォルダに登録する」をクリックします（または `backend/training_data/<画風名>/` フォルダに画像を直接置いてもOKです）。
4. **「🚀 画風学習を開始」** をクリックすると、RTX 4070 Ti のGPUで約2〜3分で学習が実行されます（リアルタイムに進捗％・残り時間が表示されます）。
5. 完了後、画像生成モードの「LoRA」ドロップダウンから学習した画風を選択し、プロンプトを入力すれば、その画風に似た新しいイラストが生成されます！

## 📡 API エンドポイント

| メソッド | パス | 説明 |
|---|---|---|
| `GET` | `/` | サーバーヘルスチェック |
| `GET` | `/api/gpu` | GPU名、VRAM使用量、モデルロード状態の取得 |
| `POST` | `/api/chat/stream` | Vision/テキスト両対応のSSEストリーミング生成 |
| `POST` | `/api/generate-image` | テキストプロンプトからの高速画像生成 (Base64返却、画風・LoRA対応) |
| `GET` | `/api/styles` | 利用可能な画風プリセット一覧の取得 |
| `GET` | `/api/loras` | `backend/loras/` 内の利用可能なLoRAモデル一覧の取得 |
| `GET` | `/api/train/datasets` | 登録済み画風データセット一覧の取得 |
| `POST` | `/api/train/dataset/upload` | 画風データセットへの画像アップロード |
| `POST` | `/api/train/start` | LoRA画風学習ジョブの開始 |
| `GET` | `/api/train/status` | 学習進行状況（％、ステップ、残り時間、Loss）の取得 |
| `POST` | `/api/train/stop` | 実行中の学習ジョブの中止 |
| `POST` | `/api/git/sync-outputs` | 生成画像の一括ローカル保存 & Gitコミット・プッシュ |
