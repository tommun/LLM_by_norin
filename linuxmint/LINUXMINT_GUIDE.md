# 🐧 LLM & Image Studio - Linux Mint 専用ガイド

Linux Mint（Cinnamon / MATE / Xfce）上で、ローカルGPUを活用した**Vision LLM対話、高精細SDXL画像生成、ControlNetポーズ固定、構図完全固定リメイク（img2img）、LoRA画風学習**をデスクトップアプリとして快適に使える統合ソフトウェアです。

---

## 🌟 主な特徴

1. **Linux Mint ネイティブGUIウィンドウ**
   - ブラウザを開く必要なく、Cinnamonデスクトップの美しいネイティブウィンドウ（WebKit2GTK）で動作します。
   - スタートメニュー（グラフィックス）およびデスクトップアイコンからワンクリック起動可能。
2. **バックエンドの自動ライフサイクル管理**
   - アプリを起動するとバックエンド（FastAPI / PyTorch / SDXL）が自動的に起動し、アプリ終了時にはGPU VRAMを安全に解放して自動クリーンアップします。
3. **フル機能の統合スタジオ**
   - **🧠 Vision LLMチャット & キャラクター設定**: Qwen2.5-VL-7Bによる高精度な画像認識対話、温度やシステムプロンプトの調整、カスタムボットの作成・編集
   - **🎨 高精細画像生成 (SDXL RealVisXL)**: 正方形(1:1)、スマホ縦長(9:16)、ポスター(3:4)、シネマ横長(16:9)のアスペクト比選択、DPM++ 2Mステップ、ガイダンススケール
   - **🦴 ControlNet OpenPose ポーズ完全固定**: 骨格ワイヤーフレームを抽出して難関ポーズも100%固定
   - **🔄 構図・手・配置固定リメイク (img2img)**: 元画像の配置を固定したままDenoise（0.55〜0.65）で高品質実写化
   - **🎓 LoRA画風学習スタジオ**: お手持ちの画像を数枚アップロードするだけで、オリジナルの画風LoRAを自動トレーニング
   - **🤖 Discord Bot連携**: Discord上でルカと会話しながら生成・リメイクできるボットの起動・設定

## 🚀 インストール手順（簡単2ステップ）

### ステップ 1: 端末（Terminal）を開く
Linux Mint のデスクトップで右クリックし、「**ここで端末を開く**」を選択するか、`Ctrl + Alt + T` を押します。

### ステップ 2: インストーラを実行
本プロジェクトの `linuxmint` フォルダに移動し、インストーラスクリプトを実行します：

```bash
cd linuxmint
chmod +x install_linuxmint.sh
./install_linuxmint.sh
```

> **インストーラが自動で行う処理**:
> 1. `apt` による必要なシステムライブラリ（Python、WebKit、OpenGL等）の自動導入
> 2. Node.js & npm のセットアップ
> 3. NVIDIA CUDA 12.1 対応の PyTorch のインストール
> 4. バックエンド依存ライブラリのインストール
> 5. フロントエンドReactアプリの最適化ビルド
> 6. Linux Mint スタートメニュー（`アプリケーション -> グラフィックス -> LLM & Image Studio`）およびデスクトップへのショートカット作成

## 🖥️ 起動方法

### 方法 A: デスクトップアイコンから（一番簡単）
デスクトップ上に作成された **`LLM & Image Studio`** のアイコンをダブルクリックするだけで起動します。

### 方法 B: スタートメニューから
Linux Mint のメニューを開き、**「グラフィックス」** または **「アクセサリ」** 内の **`LLM & Image Studio`** をクリックします。

### 方法 C: ターミナルから
```bash
./linuxmint/run_linuxmint.sh
```

## 🎛️ 各種機能の使い方

### 1. 🧠 LLM設定 & チャット
- 画面右上のギアアイコン（⚙️）から、**システムプロンプト**、**Temperature（創造性）**、**Top-P**、**最大出力トークン数**を自由にカスタマイズできます。
- 左上の **キャラクター選択** から「ルカ（プロンプト専門相棒）」や独自に作成したカスタムボットに即座に切り替え可能。
- 上部ヘッダーには、RTXグラフィックボードの **VRAMリアルタイム使用量・パーセンテージ** が常時表示され、「キャッシュ解放」ボタンで不要なVRAMをいつでもクリーンアップできます。

### 2. 🎨 高精細画像生成 (SDXL RealVisXL)
- モードを「画像生成」または「Prompt Master」に切り替えると、SDXLによる高画質生成画面になります。
- アスペクト比セレクターで `1:1`, `9:16`, `3:4`, `16:9` を選択。
- プロンプトを入力して送信すると、最高品質のリアルフォト・イラストが生成されます。

### 3. 🔄 構図固定リメイク (img2img / Denoise 0.55〜0.65)
- 入力欄のクリップアイコン（📎）から元画像を添付。
- Denoise強度を `0.60` 前後に設定して実行すると、元画像の手やオブジェクト・背景の配置を固定したまま実写化されます。

### 4. 🦴 ControlNet OpenPose（ポーズ固定）
- 人物が写っている画像を添付してポーズ固定を有効にすると、自動で骨格ワイヤーフレームが抽出され、全く同じポーズで別キャラクターを描画できます。

### 5. 🎓 LoRA画風学習スタジオ
- 左側サイドバーの「LoRA学習」タブを開きます。
- スタイル名を入力し、絵柄を学習させたい画像を3枚以上ドラッグ＆ドロップ。
- 「学習開始」を押すと、リアルタイムに進捗バー・Loss値・残り時間が表示され、数分で独自のLoRAファイル（`.safetensors`）が完成します。

### 6. 🤖 Discord Bot の同時起動
Linux Mint のデスクトップアイコンを右クリックし、「**Discord Botも一緒に起動**」を選択するか、以下のコマンドでDiscord Botを常駐させることができます：
```bash
cd backend
source .venv/bin/activate
python3 discord_bot.py
```

## 🛠️ トラブルシューティング

### Q1. NVIDIA GPUが認識されない / VRAMが表示されない
Linux Mint の「**ドライバマネージャ**（Driver Manager）」を開き、推奨されるNVIDIAドライバ（`nvidia-driver-535` または `nvidia-driver-550`）が適用されているか確認してください。
端末で以下を実行してGPU名が表示されれば正常です：
```bash
nvidia-smi
```

### Q2. ネイティブウィンドウではなくブラウザで開いてしまう
Linux Mint の WebKit ライブラリをインストールしてください：
```bash
sudo apt install -y gir1.2-webkit2-4.0
pip install pywebview PyQt5
```
